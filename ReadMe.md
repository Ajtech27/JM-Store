## 📖 Overview

Flask Market is an e-commerce platform where users can:

- **Browse** available items
- **Purchase** items using their budget
- **Sell** items they own
- **Track** their spending and inventory

This project was built as part of my transition from Data Analysis to Backend Engineering, showcasing my ability to build full-stack web applications with authentication, database design, and deployment.

---

## ✨ Features

### 🔐 Authentication
- User registration with validation
- Secure login/logout with Flask-Login
- Password hashing with Flask-Bcrypt
- CSRF protection with Flask-WTF

### 🛍️ Market Features
- Browse available items (owner = None)
- View item details (modal)
- Purchase items with budget validation
- Sell owned items
- Real-time budget updates

### 🛠️ Technical Features
- SQLAlchemy ORM for database management
- PostgreSQL/SQLite support
- Environment variable configuration
- Flask-Migrate for schema migrations
- Modular project structure
